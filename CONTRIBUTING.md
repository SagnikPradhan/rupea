# Contributing

Rupea is AGPL-3.0, and contributions stay with you. There is no agreement to sign and no copyright transfer.

Sign off every commit with `git commit -s`. That adds a `Signed-off-by` line, which says you wrote the change or have the right to submit it under the project's license, as in the [Developer Certificate of Origin](https://developercertificate.org).

Because contributors keep their rights, the license cannot be changed without asking each of them.

Before a pull request, run `pnpm verify`. How the code is written is in [AGENTS.md](AGENTS.md).
